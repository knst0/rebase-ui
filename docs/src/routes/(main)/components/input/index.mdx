# Input

A native input element that automatically works with [Field](/components/field).

<Demo hero />

## Usage guidelines

- **Form controls must have an accessible name**: It can be created using a `<label>` element or the `Field` component. See the [forms guide](https://base-ui.com/react/handbook/forms).

## Anatomy

Import the component and use it as a single part:

```jsx title="Anatomy"
import { Input } from "@rebase-ui/solid/input";

<Input />;
```
