# Meter

A graphical display of a numeric value within a range.

<Demo hero />

## Anatomy

Import the component and assemble its parts:

```jsx title="Anatomy"
import { Meter } from "@rebase-ui/solid/meter";

<Meter.Root>
  <Meter.Label />
  <Meter.Track>
    <Meter.Indicator />
  </Meter.Track>
  <Meter.Value />
</Meter.Root>;
```
