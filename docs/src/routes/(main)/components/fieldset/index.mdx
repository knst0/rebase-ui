# Fieldset

A native fieldset element with an easily stylable legend.

## Anatomy

Import the component and assemble its parts:

```jsx title="Anatomy"
import { Fieldset } from "@rebase-ui/solid/fieldset";

<Fieldset.Root>
  <Fieldset.Legend />
</Fieldset.Root>;
```
