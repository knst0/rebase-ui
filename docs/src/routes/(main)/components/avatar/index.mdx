# Avatar

An easily stylable avatar component.

## Anatomy

Import the component and assemble its parts:

```jsx title="Anatomy"
import { Avatar } from "@rebase-ui/solid/avatar";

<Avatar.Root>
  <Avatar.Image src="" />
  <Avatar.Fallback>LT</Avatar.Fallback>
</Avatar.Root>;
```
