# Field

A component that provides labeling and validation for form controls.

<Demo hero />

## Anatomy

Import the component and assemble its parts:

```jsx title="Anatomy"
import { Field } from "@rebase-ui/solid/field";

<Field.Root>
  <Field.Label />
  <Field.Control />
  <Field.Description />
  <Field.Item />
  <Field.Error />
  <Field.Validity />
</Field.Root>;
```
